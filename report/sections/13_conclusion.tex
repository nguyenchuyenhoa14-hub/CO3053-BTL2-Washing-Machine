\subsection{Executive Engineering Summary}

This project successfully designed, implemented, formally specified, and rigorously verified a commercial-grade, coin-operated washing machine control unit on the high-performance ARM Cortex-M7 WeAct STM32H750VBT6 microcontroller platform. By synthesizing rigorous theoretical state machine formalisms with modern bare-metal embedded software engineering disciplines, the resulting system achieves mathematical determinism, zero memory leakage, and complete hardware portability.

Key technical achievements delivered in this assignment include:
\begin{itemize}
  \item \textbf{Deterministic Extended FSM Core:} A mathematically formalized 6-state, 22-transition state machine operating on a 176-byte context space. The controller enforces all functional constraints and safety invariants ($I_1 \dots I_5$) with zero undefined event behaviors.
  \item \textbf{Layered Embedded Architecture:} A clean 4-tier separation upholding the Dependency Inversion Principle (DIP). The logical FSM core is 100\,\% decoupled from physical registers, enabling identical byte-level execution across host-simulated testbenches and bare-metal targets.
  \item \textbf{Zero-Drift Non-Blocking Timing Kernel:} Elimination of all blocking delay loops in favor of a monotonic SysTick time base ($1$\,ms) equipped with an automatic catch-up loop. Phase-preserving modulo arithmetic guarantees zero drift across 1.0\,Hz and 2.0\,Hz LED blinker engines.
  \item \textbf{Defensive Software Hardening:} Full alignment with MISRA-C:2012 guidelines, featuring bounded switch debouncing ($30$\,ms), temporal double-press window filtering ($1500$\,ms), saturating financial accumulators ($B \le 990$\cent), and zero dynamic heap allocation ($\text{Heap} = 0$\,bytes).
  \item \textbf{Target Integration and Ergonomics:} Deployment on a $400$\,MHz STM32H750 core with an off-screen double-buffered ST7735 TFT dashboard, 10\,kHz TIM1 PWM backlight control, and a single-key multi-gesture temporal decoder.
\end{itemize}
