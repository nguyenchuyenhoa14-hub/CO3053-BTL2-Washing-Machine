\section{Source Code Repository and Modular Organization}
\label{app:source}
% =============================================================================

The complete production source code, verification test suites, and hardware build scripts are hosted in the project repository~\cite{projectrepo}:
\begin{center}
  \url{https://github.com/nguyenchuyenhoa14-hub/CO3053-BTL2-Washing-Machine}
\end{center}

\noindent The software codebase is partitioned into four primary architectural subsystems:
\begin{enumerate}
  \item \textbf{Core Finite State Machine (\code{fsm}):} Houses the formal Moore-Mealy hybrid state engine and transition dispatcher, completely decoupled from physical microcontroller hardware.
  \item \textbf{Hardware Abstraction Layer (\code{hal}):} Contains non-blocking software debouncers, optical waveform blinkers, multi-gesture decoders, and coin pulse train accumulators.
  \item \textbf{Target Board Firmware (\code{board}):} Houses the bare-metal CMSIS startup, clock tree derivation (400\,MHz), ST7735 color LCD graphics driver, and SysTick monotonic scheduler targeting the WeAct MiniSTM32H750 board.
  \item \textbf{Automated Test Harnesses (\code{tests}):} Encapsulates all 94 automated unit tests, mock HAL stubs, and regression runners executed under host GCC.
\end{enumerate}

\noindent Standard build and test automation targets:
\begin{itemize}
  \item Execute automated test suites: \code{make test}, \code{make test_hal}, \code{make test_gesture}.
  \item Compile bare-metal target firmware: \code{make h750}.
  \item Flash firmware to target via DFU / ST-Link: \code{make flash}.
  \item Render desktop LCD dashboard preview: \code{make preview}.
\end{itemize}

    \midrule
